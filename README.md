# Simulia

Simulador de teléfono para una historia interactiva.

- `index.html`: el teléfono y el motor de historia. La historia está en el bloque `STORY0`.
- `manifest.json`, `sw.js`, `icon.svg`: hacen que se pueda instalar como app.
- Editor de historia: abre la página con `#editor` al final del enlace.
